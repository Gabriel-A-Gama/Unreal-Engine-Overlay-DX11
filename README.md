# Unreal-Engine-Overlay-DX11
Este projeto é um estudo educacional desenvolvido em C++ com foco em entender como funcionam:  - Overlays em aplicações DirectX 11 - Renderização em tempo real - Interfaces com ImGui - Estruturas internas da Unreal Engine - Leitura de atores e objetos do jogo - Hooks gráficos utilizando Kiero
